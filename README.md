# Deep Learning Practice

A hands-on learning repository focused on understanding and implementing Deep Learning concepts using **Python, TensorFlow, and Keras**.

This repository contains practical implementations, experiments, and image classification projects using different neural network architectures and datasets.

## Topics Covered

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Image Classification
- Model Training and Evaluation
- TensorFlow and Keras

## Projects

### 1. CNN – Cats vs Dogs Classification

- **Dataset:** Cats and Dogs Image Dataset
- **Framework:** TensorFlow / Keras
- **Architecture:** Convolutional Neural Network (CNN)
- **Objective:** Classify images into two categories: Cats and Dogs.
- **Concepts:** Convolution, Pooling, Flattening, Dense Layers, Model Training and Evaluation.

### 2. CNN – Fashion-MNIST Classification

- **Dataset:** Fashion-MNIST
- **Framework:** TensorFlow / Keras
- **Architecture:** Convolutional Neural Network (CNN)
- **Objective:** Classify clothing images into 10 different categories.
- **Concepts:** Image Preprocessing, Convolution, Max Pooling, Flattening, Softmax Classification and Model Evaluation.
